📊 K-pop Physical Album vs Digital Streaming Analysis
Comparative Analysis of K-pop Fandom and Mass Popularity
1. Project Overview
본 프로젝트는 K-pop 시장에서 피지컬 음반 판매와 디지털 음원 성과 간의 차이와 관계를 데이터 기반으로 분석하는 것을 목표로 한다.
특히 코로나19 이후 변화한 음악 소비 환경(스트리밍 중심 → 팬덤 중심 음반 소비 회귀)을 반영하여, 팬덤 기반 소비와 대중적 소비의 구조적 차이를 규명한다

2. Research Background


글로벌 음악 시장은 스트리밍 중심으로 성장했으나, K-pop 시장에서는 피지컬 음반 판매가 지속적으로 증가


2021년 이후 한국 음악 시장에서 피지컬 음반 판매량 재상승 확인


숏폼 플랫폼(TikTok 등)이 음원 소비에 영향을 미치기 시작


기존 연구는 코로나19 이후의 구조 변화 및 K-pop 특수성을 충분히 반영하지 못함 연구 주제 아이디어



3. Research Questions


RQ1: 음원 스코어 및 음반 판매량에 영향을 미치는 변수는 무엇인가?


RQ2: 피지컬 음반 순위와 디지털 음원 순위 간에 상관관계가 존재하는가?


RQ3: 음원 차트와 음반 차트는 어떤 구조적 차이를 가지는가? 학부 연구생 프로젝트



4. Data Sources
구분데이터글로벌 음원 데이터Spotify API (Streaming, Chart Rank)국내 음원·음반 데이터써클 차트 (Digital / Album Chart)분석 대상K-pop 주요 아티스트 및 앨범 (2018–2023)
Spotify는 글로벌 스트리밍 시장 대표 플랫폼으로 API 기반 수집이 용이하며,
써클 차트는 실물 음반·디지털 음원을 통합 집계하는 국내 기준 지표로 활용됨 연구 주제 아이디어

5. Methodology


데이터 전처리 및 변수 인코딩 (아티스트 성별, 연도, 순위 등)


OLS 회귀분석을 통한 음원·음반 영향 요인 분석


회귀 가정 검정 (정규성, 독립성, 등분산성)


상관 분석 및 시각화


차트 상위 아티스트 구성 비교 분석 학부 연구생 프로젝트



6. Key Findings
RQ1. 영향 요인 분석


음원 순위(rank)는 음반 판매량과 강한 연관성을 보이나, 다중공선성 문제 발생


단순 회귀 결과, 음원 스코어의 음반 판매 설명력은 매우 낮음


R-squared ≈ 0.015 학부 연구생 프로젝트




RQ2. 음원–음반 상관관계


상위 데이터만 활용한 분석 결과, 상관계수는 높게 나타났으나


표본 편향으로 통계적 유의성 부족(p-value 유의하지 않음) 학부 연구생 프로젝트


RQ3. 차트 구조 차이


음원 차트 상위: 솔로/여성 아티스트 비중 상대적으로 높음


음반 차트 상위: 남성 아이돌 그룹 중심, 팬덤 소비 특성 명확


음반 차트 10회 이상 진입 아티스트 전원 남성 그룹으로 확인 학부 연구생 프로젝트



7. Limitations


실물 음반은 판매 기간이 존재하여 음원처럼 장기 역주행 분석 불가


코로나 이후 음반 판매량 인플레이션 존재


써클 차트 자체 스코어 산정 기준 변화로 연도 간 비교 한계 학부 연구생 프로젝트



8. Implications


디지털 음원과 피지컬 음반은 서로 다른 소비 메커니즘을 가짐


K-pop 시장에서는 글로벌 대중성(음원)과 팬덤 충성도(음반)를 분리해 해석할 필요성 제시


음악 산업 데이터 분석 시 플랫폼·차트 특성을 고려한 모델 설계 필요 학부 연구생 프로젝트
